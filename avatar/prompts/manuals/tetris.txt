This is Tetris. Seven tetrominoes (I O T S Z J L) fall in a 10-column × 20-row well.
Columns are 0 (far left) through 9 (far right). Pieces spawn near column 3.
Goal: complete full horizontal lines. Game over if a new piece cannot spawn.

Named actions:
- shift_left / shift_right — one column
- rotate / rotate_ccw — clockwise / counter-clockwise
- soft_drop — down one row (rarely useful)
- hard_drop — lock now (use this to place, not to panic)
- hold — swap with hold (once per piece). Save I for a 4-wide well; hold a bad piece.
- start / restart / pause / resume — only if idle or game over

Strategy (follow every turn):
1. Keep a FLAT stack. Never cover a hole. Never build a spire in the middle.
2. 9-0 well: fill columns 0–8 left-to-right. Keep column 9 EMPTY for a vertical I (Tetris).
3. Do NOT hard_drop in the spawn column unless that is already the lowest flat fit.
4. Each JSON plan should FINISH the current piece: rotate as needed, shift to the target
   column, then hard_drop. Do not spend later turns nudging the same piece.
5. O and I (flat): park on the lowest flat 2-wide / 4-wide shelf. Vertical I: only in the well.
6. S/Z: prefer a stair that does not create a hole. If it would hole the stack, hold it.
7. If gravity is running, still align then hard_drop — do not dump from spawn.
