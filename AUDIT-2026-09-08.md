## Findings to fix, in order

### P0 — target failures poison later snapshots

Confirmed in `runs/20260908T202041Z_sts2_collect` and traced to [`loop/agent/loop.py`](loop/agent/loop.py):

- A missing post-selection rebound records the target as blocked (`_record_blocked_target`).
- `_build_turn_snapshot` then removes that id through `_target_is_blocked`.
- The block clears only when host enemy count changes. A transient miss with the same one live enemy therefore persists; if the stored count is `None`, the existing guard can prevent clearing indefinitely.
- Run sequence: step 1 blocks `enemy_1`; step 2 publishes no target; step 4 blocks replacement `enemy_2`; later snapshots remain targetless despite visible enemy evidence.

At the audit snapshot the incomplete run had 16 turns, 2 target-not-found errors, 14 targetless snapshots, 12 `effect-unverified` actions, 14 forced rescans, zero reward, and no finalized episode or summary.

**Fix:** scope target rejection to the failed snapshot/frame generation, or clear it after a forced rescan/current inventory change. Add a replay test proving that a transient rebound miss cannot suppress the sole visible enemy on the next fresh snapshot.

### P0 — the repository is not reproducible from Git

HEAD tracks only 104 files while the workspace contains 392 untracked files (190 collapsed entries in `git status`). Essential install/runtime files such as `pyproject.toml`, `requirements.txt`, `loop/config.py`, `loop/model/gateway.py`, fixture/state modules, and many tests are untracked even though tracked code imports them. A clean clone of HEAD cannot import or run the current system.

**Fix:** review and commit the intended implementation/config/test files as a coherent checkpoint. Do not blanket-add `.env`, run captures, logs, temporary scripts, editor state, or model artifacts. Verify the checkpoint from a fresh worktree before relying on any green result.

### P1 — duplicate-target collapse can erase a real enemy

`collapse_duplicate_named_targets` merges same-named targets whenever their x-ranges overlap, without a y-distance, overall-distance, or host-count constraint. Two distinct same-named enemies with slightly overlapping boxes can collapse into one. The current side-by-side test uses fully disjoint narrow boxes and does not cover this case. The merge can also retain one id/bbox while copying the other row's name/HP, producing a semantically mismatched target.

**Fix:** require stronger same-sprite evidence (vertical-stack geometry plus distance/IoU and host-count consistency), and add fixtures for two legitimate same-name enemies with partial x overlap, staggered positions, and different HP.

### P1 — the ordinary full test command aborts

Plain `pytest -q` exits during collection because `tests/test_memory.py` and `tests/loop/test_memory.py` both import as top-level module `test_memory` under pytest's default mode. The code tests pass with importlib collection.

**Fix:** set pytest import mode to `importlib` in `pyproject.toml`, package the test directories, or rename one file. The documented one-command health check must succeed without a special workaround.

### P1 — runtime contract had drifted from the documentation

Before this audit, `system.md` described overlay as the STS2 default, Qwen 9B as the default second model, and Grounding DINO as mandatory. Code currently defaults STS2 to `two_stage`, both model slots to cloud Gemma, YOLO GUI on, and DINO off unless `--dino` is passed. The file also described the older mark/chord reasoning path instead of ActionIntent v2.

**Action taken:** `system.md` now records the actual defaults, current ActionIntent flow, Batch 7 gate, safe regression commands, and source-of-truth hierarchy.

### P2 — maintainability and drift controls are weak

- `loop/os/window.py` uses deprecated `mss.mss()`; the full suite emits one warning. Verify and migrate to `mss.MSS()` before the dependency removes the alias.
- No Ruff, mypy, or pyright check is installed/configured.
- Dependency versions use lower bounds only; `torch` is unpinned and model ids/revisions can float. Fresh environments may not reproduce this audit.
- Local logs, monitor state, temporary scripts, and editor metadata are visible as untracked workspace noise. Review narrow ignore rules without hiding useful fixtures or reports.
