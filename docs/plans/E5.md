### E5.1: Capture

- **Goal:** reliable capture of a game window's client area on Windows. No focus is needed for capture.
- **Create or change:**
  - Install `windows-capture` with `uv pip install --python .venv-agent/Scripts/python.exe windows-capture`.
  - `agent/capture_win.py`:
    - `ensure_dpi_aware()` runs **before any window call**.
    - `find_window(title_substr)`.
    - `grab(target) -> Image` tries WGC, then PrintWindow, then ImageGrab. It **captures the client area, not the whole window**, and rejects black or partial frames.
    - `focus(target)`, `is_foreground(target)`.
    - `client_to_screen(target, at) -> (x, y)` **maps to the true last pixel**: a fraction of 1.0 maps to width − 1.
- **Tests (pure parts only):**
  - `client_to_screen` edges: 0, 1.0, and an offset client origin;
  - the black-frame classifier;
  - a capture smoke test on any visible window, skipped unless `RUN_WIN_TESTS=1`.
- **Acceptance:** `.venv-agent/Scripts/python.exe -m pytest tests/agent/test_capture_win.py -q`
- **Done when:** the tests are green, the file is ≤ 230 lines, and nothing is imported from `loop/`.

### E5.2: Input

- **Goal:** safe, exact input.
- **Create or change:** `agent/input_win.py`:
  - **Scan codes**, with the **extended-key flag for arrow keys**.
  - `tap(key, ms)` and `hold(key, ms)` **never leave a key held**: release in `finally`.
  - `release_all()` runs at start and at exit (`atexit`).
  - `click(screen_xy, button="left")` uses absolute virtual-desktop coordinates, so it works across **multiple monitors**.
  - **Before any input, check `is_foreground(target)`.** If the game isn't in front, raise `InputBlocked` rather than send anything.
- **Tests (pure parts):** scan-code compilation and the extended flag on arrows; virtual-desktop normalization on two monitor layouts; `hold` releases on exception (with an injected `send_input` stub).
- **Acceptance:** `.venv-agent/Scripts/python.exe -m pytest tests/agent/test_input_win.py -q`
- **Done when:** the tests are green and the file is ≤ 170 lines.

### E5.3: WindowEnv, brief, tools

- **Create or change:**
  - `agent/env_window.py`: `WindowEnv(title_substr, name)` implements `Env`:
    - `pointer = True`;
    - `screenshot = grab`;
    - `press` and `click` go through `input_win`, after a single focus at construction;
    - `tick(frames)` sleeps `frames / 60`.
    - **Kill switch:** if the cursor is in the top-left corner (0, 0) of the primary screen, every subsequent input raises, and the loop checkpoints and exits.
  - `agent/briefs/sts2.json`: a trimmed copy of the existing brief, ≤ 8 KB.
  - `scripts/check_window.py --title "Slay the Spire 2"`: captures one frame, saves it, and clicks the centre of the client area **only with `--click`**. It prints the capture method and size.
  - `scripts/spot_check.py runs/<id> --n 40`: samples steps and writes a `spot_check.md` with before and after frames and the trace row for each, which the orchestrator fills in as judgments. It then aggregates them into `spot_check.json`.
  - `scripts/run_agent.py`: add the env dispatch for `--game sts2 --title …` (≤ 5 lines). `scripts/` is not core, so this doesn't count against the core diff.
- **Acceptance:**
  - `.venv-agent/Scripts/python.exe -m pytest tests/agent -q`
  - `.venv-agent/Scripts/python.exe scripts/check_window.py --title "Slay the Spire 2"` saves a correct client-area frame, without `--click`.
- **Done when:** the tests are green, the smoke frame is visually right, and the core diff is empty.
