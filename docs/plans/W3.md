**Run order:** W3.1 → W3.2

### W3.1
- **View rectangle** (metric places only): the player tile `pos`, the player's screen tile (from `_anchor`), and the screen size in tiles give the place-frame tiles currently on screen. Shrink by 1 tile on each side for misses; use the full rectangle for `seen`.
- **Misses** only when the frame hash differs from the last frame that counted, `screen == "world"`, and no modal is open. Unmatched interest/landmark entities of this place inside the shrunk rectangle get `misses += 1`; status `stale` at `MISS_TO_STALE = 2`, `gone` at `MISS_TO_GONE = 4`. A match sets `status = "seen"`, `misses = 0`. Non-matched entities elsewhere: `seen` → `remembered`.
- **Actors** (W2 stand-in kinds): `remembered` → `stale` when `step − last ≥ ACTOR_STALE_STEPS = 20`; misses ignored. `memory.observe` widens the match radius for actor kinds to `min(4, 1 + (step − last) // 4)` tiles.
- **`seen` store:** one row per place `{"id": place, "cells": ["x,y", ...], "step"}`, upserted only when new cells appear.
- **Tiers** (§3.3): set on observe and on events (interacted, blocked a move, named in a notebook goal or on-screen text). Landmarks beyond `LANDMARKS_PER_PLACE = 8` per place (fewest `seen` first) are not shown, not deleted.
- **Invented exits:** an `exit:` entity whose tile is known floor with no `exit`, and that was tested and failed (a `leads_to` relation refuted or a failed edge), stays landmark tier.

### W3.2
- `World.view(goal_text, place)` renders, within `VIEW_TOKENS = 500` (`len / 4`), in this order: Here line (`Here: <name> (x,y)  map: N walked, M seen, K untried edges (U into unseen)`); the map cropped to `MAP_W × MAP_H = 21 × 15` around `@` with the legend from world-memory.md §3.6; things here (interest tier: name, tile, kind stand-in, status, last step); other places ranked by hops, then word overlap with `goal_text` (active notebook goals), then recency, each with name, aliases, exits (`→ name`), interest things with status, untried/unseen edge counts; then the current flags. Gone things never appear. Deterministic for the same memory.
- Loop act branch: replace `describe(...)` with `world.view(goals_text, place)` and pass known place names from W1. The gated branch keeps `describe` until P4.
- `check_world.py view`: render on a copy of checkpoint-94 memory, print it, check length and determinism.
- **Acceptance:** `pytest tests/agent/test_world.py tests/agent/test_loop.py tests/agent/test_world_golden.py -q`; `scripts/check_world.py view`; full suite.
