### P2.1: `scripts/eval_act.py`
- **Goal:** for a list of frame steps, run perceive + act in order with one shared notebook, and record everything needed to judge the act prompt.
- **Behaviour:**
  - Args: `--frames 6,12,44,46,48,51,53,56,62,67,68,70,76,85,94` (default), `--max-calls N` (required), `--out .tmp/p2`.
  - For each step: load `runs/m1/frames/{step:06d}.png`; `perceive()` with the same context the loop builds for the perceiver (brief + `GENERAL`, no memory view); `act()` with `notebook.render()`, `facts="none"`, `flags=[]`, controls/prefs/buttons from the brief and `PyBoyEnv` input names (no emulator needed: use the brief's controls and the env's static input list).
  - Apply notebook ops (`Notebook(.tmp/p2/notebook)`), so place naming across frames is testable.
  - Every model request reserves through `scripts/run_agent._ledger(Path("runs/m1_p2"), None, cap)` (M1 bucket) **before** posting. Wrap `model._post` like `scripts/run_goal.py` does. Stop cleanly at `--max-calls`.
  - Write `.tmp/p2/rows.jsonl` (step, screen, text, entities count, affordances, act reply raw + parsed, notebook ops, truth map), `.tmp/p2/summary.json` (the gate metrics in §2), `.tmp/p2/table.md` (one row per frame: step, truth map, screen text (≤ 80 chars), place named, action, why, goals added).
  - Truth is read only to fill the truth column and the purity metric.
- **Acceptance:**
  - `.venv-agent/Scripts/python.exe -m pytest tests/agent/test_eval_act.py -q` (StubModel replies; checks the ledger wrapper is called once per request, metrics on a 3-frame fixture, cap stop).
- **Done when:** acceptance exits 0, budgets hold, no imports from `loop/`.
- **Risks:** perception cache misses (P1 changed the perceiver prompt), so expect 2 requests per frame → 30 for 15 frames. Mitigation: the cap; the cache still serves any repeat.
