### W1.2
- `World.name(place, name, step)`: find a non-merged place `T` (≠ `place`) whose name or alias equals `name` (casefold).
  - None → `mem.name_place(...)` (adds the alias) → `place`.
  - `place` is a new arrival (`first == step`) → `mem.name_place(...)` (existing merge) → `T`.
  - Otherwise (both established) → `merge(place, T, step)`; on success return `T`, else add the alias, append flag `merge_pending: <name>`, return `place`.
- `World.merge(src, dst, step)`: offset = median of `(dst_tile − src_tile)` over entities with the same `_base` name present with tiles in both places; needs ≥ 2 pairs that agree within 1 tile, else return False. On success:
  - every `tiles` row of `src` is rewritten as `dst@(x+dx, y+dy)`. If the target cell exists, keep `floor` true if either is; union `blocked`/`pushed`; keep a non-null `exit`;
  - `src` entities get `place = dst` and shifted tiles; same-name duplicates within 1 tile collapse into the `dst` record (`seen` summed);
  - edges, tile exits, relations pointing at `src` are redirected (reuse the code path in `name_place`);
  - `src` row: `state: merged, into: dst, offset: [dx, dy]`;
  - if the player is in `src`, `pos` shifts by the offset.
- Ponytail note: append-only JSONL keeps the pre-merge rows, so a bad merge is recoverable by truncation; no undo code.
- **Acceptance:** `pytest tests/agent/test_world.py -q`; full suite.

### W1.3: `scripts/check_world.py merge`
- Copy `runs/m1/checkpoint/000094/memory/` to `.tmp/w1/memory/`.
- Map each place id to truth maps from `runs/m1/trace.jsonl` + `truth.jsonl` (evaluation only; same logic as `eval_run`).
- For each pair of ids sharing a truth map: compute the truth offset from steps where both ids have a trace `tile` and truth `(x, y)`. Call `World.merge` and compare. Print a table (pair, eligible landmark pairs, computed offset, truth offset, verdict). Exit 0 if wrong merges = 0 and, when at least one pair is eligible (≥ 2 shared landmark base names with tiles), correct merges ≥ 1. If no pair is eligible, exit 0 and print `no eligible pair`; the gate then rests on the unit tests (clarified 2026-10-12, same rule as the gate table).
- **Acceptance:** `.venv-agent/Scripts/python.exe scripts/check_world.py merge` exits 0.
