### W0.1: golden episodes
- **Goal:** freeze today's spatial behaviour as data.
- **Create:** a test module with two scripted GridEnv episodes driven through `Loop.step` with StubModel replies:
  1. the gated path, reusing the scenario of `test_grid_loop_reuses_two_spatial_exits_between_floors` (two floors, stairs both ways);
  2. the act path (`act_mode=True`), 8 steps with scripted act replies including one `go_to` of an on-screen entity and one `buttons` move.
  
  A `--regen` switch (environment variable `W0_REGEN=1`) writes the memory stores and trace rows (minus `t`, `ms`) into `tests/agent/data/w0_golden/<episode>/`. Without it, the test compares.
- **Acceptance:** `W0_REGEN=1` run once at HEAD, then `.venv-agent/Scripts/python.exe -m pytest tests/agent/test_world_golden.py -q` passes at HEAD.
- **Risk:** nondeterminism (dict order, timestamps). Mitigation: compare parsed JSON rows sorted by `id`; drop `t`/`ms`.

### W0.2: extraction
- **Goal:** all spatial state and bookkeeping for the act path lives in `agent/world.py`.
- **Move into `class World` (no behaviour change):**
  - state: `pos`, `drift`, `drift_ref`, `entity_tiles`, `entity_ids`, `anchors`; `_anchor()`;
  - the projection (`proj` lambda) and the per-entity `tiles` dict;
  - the `mem.observe(per, place, step, tiles)` call that uses those tiles;
  - `pos` resets on a place change and on a known-exit arrival;
  - the `fold` call after the skill, the `exit_key`/`cut_dir` computation, `exit_to` and `mark_exit` on a cut.
- **Interface (contracts.md#world):** `World(mem, tile_px)`; `before(per, place, prior, size, step) -> (proj, tiles, ids)`; `after(skill, place, next_place, scene_cut, step) -> dict` (the values the loop still needs: `exit_key`, `cut_dir`, `known_exit`); `state() -> dict`; `restore(dict)`. `Loop.state()` keeps the same harness keys (`pos`, `drift`, `drift_ref`, `entity_tiles`, `entity_ids`, `anchors`) so existing checkpoints load.
- **Leave in `loop.py`:** the gated branch's candidate logic (`navigation_candidates`, `next_test`, `route`/`outward`/`frontier` calls). P4 deletes it.
- **`memory.py`:** replace the lazy `from agent.space import exit_to` in `match_place` with a direct `tiles` lookup (same semantics).
- **Trace additions (contracts.md#trace, 2026-10-12):** `entities`: the before-perception entities as `[{"id", "name", "kind", "at"}]`; `scroll`: the skill's total `[dx, dy]` or null. Used by W4 offline.
- **Acceptance:**
  - `.venv-agent/Scripts/python.exe -m pytest tests/agent/test_world_golden.py tests/agent/test_loop.py tests/agent/test_space.py tests/agent/test_memory.py tests/agent/test_act.py -q`
  - full `tests/agent` suite.
- **Risks:** `loop.step` is dense and shared by both paths. Mitigation: move only the listed lines; the golden test is the referee.
