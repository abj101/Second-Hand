### W2.1
- `ACTOR_KINDS = {"person", "npc", "character", "enemy", "monster", "animal"}` in `world.py` (compared on `memory.normalize_kind`). Game-neutral words only.
- `World.before` collects the tiles of on-screen entities whose kind is in `ACTOR_KINDS` and passes them to `fold(..., actors=...)`. In `fold`, a confident `(0, 0)` press whose destination tile is in `actors` records nothing.
- `ponytail:` comment: kind stand-in until W4 classifies anchors from motion.

### W2.2
- `resolve` order: on-screen entity by name (today's rule) → remembered entity (`_base` match, `_distance ≤ 1`, status not `gone`, has a tile and a non-merged place) → place by name or alias (target = an arrival tile of an exit into it; else its first floor tile). Several matches: same place first, then fewest hops, then most `seen`.
- `plan`: BFS over non-merged places, edges = tile exits with known `to`; per leg `space.route(...)` to the exit tile + its `dir`; last leg routes to the target tile (an entity: the nearest floor neighbour, plus a facing press). Unknown tiles are passable (existing rule). `None` if there is no path.
- `travel`: for each leg, `skills.approach(ctx, ..., route={"dirs", "push"})`. After a leg that should cut, check `exit_to`/arrival; on a mismatch update the stored `arrive` to the observed tile, stop, and return. Fold moves per leg. Stop on a blocked leg with no alternative, a modal (dialogue/menu) opening (reuse `observer.cut`/`changed` signals the skill already reports), or `TRAVEL_MAX_INPUTS = 120`. Return one combined `SkillResult` (inputs summed; reason `"travel: <leg n> <what>"` or `""`).
- Loop act branch: `go_to` → `world.resolve`; a screen result keeps today's approach path; memory/place results call `world.plan` + `world.travel` as the step's skill; `None` → flag `go_to "<name>": not in memory` and `wait_until`, as for a missing action today. No perception or act call happens inside travel.
- **Acceptance:** `pytest tests/agent/test_world.py tests/agent/test_loop.py tests/agent/test_world_golden.py -q`; full suite.

### W2.3: `scripts/check_world.py graph|travel|fetch`
- Copy checkpoint 94 (state + memory) to `.tmp/w2/`. Build `PyBoyEnv` + `Ctx` + `World` like `scripts/run_goal.py`; model = StubModel that raises on any call.
- `graph`: print places, names/aliases, exits; exit 1 if no 2F → 1F → Town chain.
- `travel`: pick the place id whose trace steps map to truth 0x00 (evaluation only), `resolve` it by its name, `plan`, `travel`; read truth after; print legs; exit 0 on the gate numbers.
- `fetch`: pick a remembered 1F entity with a tile that is not an exit (the first by `seen`), same flow, check truth map 0x25 and adjacency in the 1F frame.
