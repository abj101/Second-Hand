### E2.2: Observer

- **Goal:** change, settle, scroll and cut signals from pixels only, robust to Game Boy animation.
- **Read:** [observer](contracts.md#observer). Copy nothing from `loop/`.
- **Create or change:** `agent/observer.py`, numpy only:
  - **`wait_settled`:**
    - keeps a ring of frame hashes (`hashlib` on the bytes);
    - a frame is quiet if its hash is already in the ring;
    - the screen is settled after `quiet` consecutive quiet frames that are not near-uniform;
    - `blank_seen` is set if any near-uniform frame (≥ 95% one colour) appeared.
  - **`scroll(a, b, max_shift=4)`:**
    - brute-force search over the shifts, minimising mean absolute difference on the overlap;
    - return `None` when the best and second-best differ by less than a documented margin.
  - **`changed`**, **`cut`**, **`snap`** and **`for_model`**, per the contract.
- **Tests (synthetic images only, plus a 10-line stub env):**
  - `scroll` recovers (2, 0) and (0, −2) on a 16-px-periodic tile texture with a few distinct sprites;
  - `scroll` returns `None` on a perfectly uniform image;
  - summing 8 frame-to-frame scrolls gives 16;
  - `wait_settled` settles on a stub that loops between 3 frames (animation), does **not** settle while a "text" region gains pixels every frame, never returns a blank frame, and sets `blank_seen`;
  - `cut` is true when `blank_seen` is set, and false for a 2-px scroll.
- **Acceptance:** `.venv-agent/Scripts/python.exe -m pytest tests/agent/test_observer.py -q`
- **Done when:** the tests are green, the file is ≤ 80 lines, and there is no FFT and no OpenCV.

### E2.4: Skills, effects, verdict

- **Goal:** closed-loop skills that never retry forever, and a verifier that labels each effect by its basis.
- **Read:** [skills](contracts.md#skills), [predict](contracts.md#predict), [observer](contracts.md#observer), [trace](contracts.md#trace), spec §7, and spec §8 "Prediction and verification".
- **Create or change:** `agent/skills.py`:

| Skill | Behaviour |
|---|---|
| `approach` (pad) | Compute the tile delta from `target_at − player_at` and `tile_px`. Step along the longer axis with `press(dir, ctx.move_frames, on_frame=…)`, summing `scroll` frame by frame. A `None` frame is skipped; if every frame of a move is `None`, measure again across the settled frames. A summed `(0, 0)` means that axis is blocked: try the other one, and return `blocked` if both are. Update the delta from the summed scroll; no model call. When the delta is 0 and there was no cut, press once more in the last direction. Return `done` on delta 0, on delta 1 and blocked (adjacent), or on `cut()`, with reason `"scene cut"`. |
| `tile_px` | The smallest non-zero absolute summed scroll seen. |
| `interact` | `approach`, then face the target, then A, then `wait_settled`. Returns `done` if anything changed. |
| `select(item)` | **One** model call returns `{"items", "cursor", "layout"}`. Then the arrow presses, then A. The step's post-perception verifies the result. |
| `advance`, `cancel`, `press`, `wait_until` | Per the contract. |
| `run_affordance` | Dispatch by verb. `click` on a pad env returns `blocked` ("no pointer"). `type` returns `blocked` until E3. |

  - On a pointer env, `approach` and `interact` call `refine` and then `env.click`.
  - `agent/predict.py`: `EFFECTS`, `PRED`, `effects()` with `basis`, and `verdict()`.
    - `view_scrolled` and `place_changes` (from a cut) have basis `pixel`.
    - `text_appears` is `pixel` only if the frame also changed in the region where the new text sits; otherwise `model`.
    - `entity_appears` and `entity_disappears` are `model`.
- **Tests (`GridEnv` and `StubModel`):**
  - `approach` reaches a target 3 tiles away in 3 moves;
  - `approach` goes around a wall;
  - `approach` returns `blocked` when boxed in, within `max_inputs`;
  - `approach` through a door returns "scene cut", with `blank_seen`;
  - `approach` does the extra push on a door mat;
  - `interact` gets the text box;
  - `select` moves from index 0 to 2 with 1 model call;
  - the basis labels;
  - the verdict cases: hit, partial, surprise, miss and unobservable.
- **Acceptance:** `.venv-agent/Scripts/python.exe -m pytest tests/agent/test_skills.py tests/agent/test_predict.py -q`
- **Done when:** the tests are green, the budgets hold, nothing is game-specific, and no skill can exceed `ctx.max_inputs`.
- **Risks:** a short press only turning the player, or a long one moving two tiles. `move_frames` is the calibration knob; E2.6 measures it against RAM.
